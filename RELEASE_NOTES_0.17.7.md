# Arbor 0.17.7

- Added independent **Blur** and **Gradual** appearance switches, producing gradual blur, panel blur, gradual panel, and normal panel modes.
- Improved the gradual tint falloff and preserved the 16 dp minimum blur.
- Dropdown menus and anchored link popups now dismiss outside only after pointer release, allowing edge Back gestures to complete.
- Preserved chat scrolling, drawer arbitration, Room schema, and signing compatibility.
