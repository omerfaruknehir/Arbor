# Xylune 0.19.10

This release repairs Xylune slider snapping and presentation. Snap anchors now exert a strong but continuous spring force during drag and settle with a damped spring animation after release. Explicit snap points are marked with track dots. The edge-softness control shows **Hard edges** throughout its rounded-to-flat 0% lane and displays a percentage only when actual feathering begins after the second dot. The Thinking slider remains continuous under the finger and springs to the nearest effort only after release.
