# Xylune 0.15.0

This release simplifies the chat composer.

- Think and Search appear as compact controls above the input field.
- The input row contains only Add, the message field, and Send/Stop.
- Nothing is rendered below the input field.
- Thinking effort remains available through the Think dropdown; no effort slider is shown.
- Files, photos, camera, Deep Research, Python, and Linux remain in the Add sheet.
- The old context progress strip was removed because context controls already exist in Chat configuration.

Database schema and saved-chat formats are unchanged from 0.14.0.
