# Xylune 0.20.12

## Fixed

- The left-edge Android back gesture now works from the main Settings menu and returns to Chat, matching the right-edge gesture.
- Settings no longer lets the drawer pull-to-open recognizer steal the left-edge back gesture.
- The drawer remains available from the Settings hamburger button.

## Build

This is an optimized, minified release APK. Developer settings and the performance overlay remain available in-app.
